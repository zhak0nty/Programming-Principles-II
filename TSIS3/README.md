# TSIS3 Racer

## Run

```bash
cd TSIS3
../.venv/bin/python main.py
```

## Controls

- `Left/Right` - switch lane
- `Esc` - back to menu from game
- Mouse click - UI buttons

## Includes

- Main Menu, Settings, Leaderboard, Game Over
- Username input before menu
- Road hazards, traffic, safe spawn logic, difficulty scaling
- Power-ups: nitro, shield, repair (only one active at once)
- Score and distance meter
- Persistent `settings.json` and `leaderboard.json`
