# Practice 09: Game Development with Pygame - Part 1

This folder contains three mini-projects:

- `mickeys_clock` - real-time minute/second clock
- `music_player` - keyboard-controlled player (`P/S/N/B/Q`)
- `moving_ball` - arrow-controlled red ball with boundary checks

## Setup

```bash
pip install -r requirements.txt
```

## Run

```bash
cd mickeys_clock && python main.py
cd music_player && python main.py
cd moving_ball && python main.py
```
