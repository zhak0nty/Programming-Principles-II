# TSIS2: Extended Paint

## Run

```bash
cd TSIS2
../.venv/bin/python paint.py
```

## Features

- Pencil (freehand) drawing
- Straight line with live preview
- Brush sizes: 2 / 5 / 10 (keys `1`, `2`, `3` and toolbar buttons)
- Flood-fill tool
- Text tool (click, type, Enter confirm, Escape cancel)
- Save canvas with `Ctrl+S` to timestamped `.png`
- Shapes from Practice10/11: rectangle, circle, square, right/equilateral triangle, rhombus
